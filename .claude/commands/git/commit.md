---
description: 불필요한 코드 정리 후 커밋 생성
---

다음 순서로 진행해주세요.

1. **불필요한 코드 탐지·제거**: 변경된 파일(없으면 관련 파일)에서 아래를 찾아 제거한다.
   - 미사용 import / 미사용 변수·함수
   - 도달 불가능한(죽은) 코드, 주석 처리된 옛 코드
   - 불필요하거나 자명한 주석 (동작을 바꾸는 주석·설명 주석은 유지)
   - 남겨진 `console.log` 등 디버그 흔적
   실제 동작에 필요한 코드는 절대 지우지 말 것. 애매하면 지우지 말고 남긴다.

2. **검증**: 정리 후 코드가 여전히 정상인지 확인한다. dev 서버가 떠 있으면 브라우저로,
   아니면 `npm run build`(dev 서버 꺼진 상태에서)로 타입·빌드를 확인한다.

3. **커밋 생성**: 변경사항을 분석해 의미 있는 단위로 커밋한다. 커밋 메시지는 한국어로,
   무엇을 왜 정리했는지 요약한다. push는 별도 요청이 있을 때만 한다.
