## 1. 발행자 결정 (PRD 13.2)

| ID | 질문 | 결정 | 근거·영향 |
|----|------|------|----------|
| **Q-1** | 공급자(자사) 정보 위치 | **환경변수 고정** | 1인 사업자라 자사 정보 변동이 거의 없음. `.env`에 고정 → 노션 스키마 단순화, 모든 견적서에 자동 반영. 스키마에 공급자 속성 불필요. |
| **Q-2** | 유효기간 미입력 허용 | **무기한 허용** | PRD 8.2 매핑 기본값과 일치. 미입력 시 만료 판정 안 함, 공개 뷰에 "유효기간 별도 협의" 표시. 링크 유출 리스크(R3)는 폐기 기능(F-07)·비색인(F-10)으로 방어. |
| **Q-5** | 접근 로그 보관 기간 | **90일** | PRD 기본값. 열람 확인에 충분하고 개인정보 최소보관 원칙에 부합. IP는 원문 대신 해시 저장. (구현은 4단계 F-21, 스키마·정책은 지금 확정) |
| **A-4** | 노션 스키마 구성 주체 | **Claude가 Notion MCP로 생성** | PRD 8.2/8.3 매핑표대로 견적서·견적품목 DB를 생성하고 relation 연결. 사용자는 워크스페이스 접근 승인만. T3에서 진행. |

### 결정이 스키마에 미치는 영향 (T3 반영 사항)
- **Q-1 → 공급자 정보 속성 제외**: 견적서 DB에 공급자 관련 속성을 만들지 않는다(환경변수로 처리).
- **Q-2 → `유효기간(date)`은 선택 속성**: 필수 아님, 비어 있어도 발행 허용.
- **Q-5 → 로그 스키마는 4단계**: 1단계 스키마엔 포함하지 않되 90일·해시 저장 정책을 기록만 해둔다.

## 2. PRD 10.4 Notion API 검증 체크리스트 (A-7 추적)

> **상태 규칙**: 착수 시 전부 `⚠️ 검증 필요`. T2(문서 검증 스파이크)·T7(raw 조회 실측)에서 공식 문서로 확인한 뒤
> `✅ 확인됨`으로 갱신하고 **출처 URL**을 남긴다. 6항목 전부 `✅`가 되면 A-7 해소 = 1단계 완료 기준 충족.

| # | 항목 | 현재 이해 | 상태 | 출처 URL |
|:-:|------|----------|:----:|----------|
| 1 | **버전 헤더** | `Notion-Version` 헤더 필수. 고정할 버전 문자열 미확정 | ⚠️ 검증 필요 | _(T2에서 기입)_ |
| 2 | **DB 조회 엔드포인트** | database/data source 개념 분리 변경 있음. 엔드포인트 경로·요청 형태 미확정 (**추측 금지**) | ⚠️ 검증 필요 | _(T2에서 기입)_ |
| 3 | **relation 확장** | relation은 ID 목록만 반환, 대상 페이지 별도 조회 필요 가능성. 25건 초과 시 페이지네이션 | ⚠️ 검증 필요 | _(T2에서 기입)_ |
| 4 | **레이트리밋** | 통합당 초당 약 3회, 초과 시 429 + `Retry-After` (수치 미확정) | ⚠️ 검증 필요 | _(T2에서 기입)_ |
| 5 | **요금** | Notion API 자체 과금 여부·한도 미확정 | ⚠️ 검증 필요 | _(T2에서 기입)_ |
| 6 | **첨부/이미지 URL** | 반환 파일 URL이 시간 제한 서명 URL로 추정 → 캐시 HTML 직박 시 만료 위험 (F-24 관련) | ⚠️ 검증 필요 | _(T2에서 기입)_ |

**A-7 해소 정의**: 위 6항목이 모두 `✅ 확인됨`(출처 URL 포함) + 견적서 1건 raw 조회 콘솔 출력 성공(T7).
