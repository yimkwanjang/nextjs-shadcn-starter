# 광고 소재 설계안 — 4가지 심리 소구 · 시각적 다양성 · A/B 승자 독식 · 메시지 매칭

> 출처: 사용자가 제공한 서적 발췌 이미지 4장(137~140p, "13 잠자는 동안에도 매출을 만드는 광고 소재 자동화") 전사.
> 자동화 설계는 [`02-automation-architecture.md`](./02-automation-architecture.md) 8절.

## 4. [실전 1] AI로 '클릭을 부르는 카피' 100개 뽑아내기

사람은 보통 **3~4개**의 카피를 떠올릴 수 있지만 그 범위가 제한적이고 비슷한 내용에 그치기 쉽다.
반면 챗GPT는 인간 심리학을 바탕으로 **1분 만에 100개**의 독창적인 카피를 만들어낼 수 있다.

### 마케팅 프레임워크 적용 프롬프트

```
[제품] 무선 칫솔 살균기
[타깃] 위생에 민감한 자취생
[요청] 아래 4가지 심리학적 기법을 적용해서 인스타그램 광고용 카피를
       각각 5개씩 작성해줘. 이모지를 사용해서 눈에 띄게 해줘.
```

### 4가지 심리 소구

| # | 소구 | 강조점 | 예시 |
|:-:|------|--------|------|
| 1 | **공포 소구** (Fear & Pain) | 안 썼을 때의 **위험성** | "변기보다 더러운 칫솔을……" |
| 2 | **사회적 증거** (Bandwagon) | 남들도 다 쓴다는 **대세감** | "3차 완판, 리뷰 5,000개……" |
| 3 | **파격 혜택** (Urgency) | 지금 안 사면 손해라는 **긴급성** | "오늘만 1+1……" |
| 4 | **호기심 유발** (Curiosity) | 클릭하지 않고는 못 배기게 만드는 **의문문** | "양치해도 입 냄새가 나는 이유가……" |

> 이렇게 나온 카피들을 **엑셀에 정리해두면, 이것이 당신의 전략 자산**이 된다.
> **당신이 보기엔 별로라고 해도, 고객이 '공포'에 반응할지 '혜택'에 반응할지는 아무도 모른다.**
> 결국 다양한 카피를 만들어서 시도해보는 것이 중요하다.

## 5. [실전 2] AI 이미지로 '시각적 다양성' 확보하기

카피가 준비되었다면 이미지를 만들 차례다. **중요한 것은 '다양한 앵글'이다.**

| # | 활용 | 성격 | 방법 |
|:-:|------|------|------|
| 1 | **제품 중심 – 배경 삭제** | 깔끔함이 무기 | 나노 바나나로 **배경을 바꿔가며 10장** |
| 2 | **모델 중심 – 페이스 스왑** | 사람이 나와야 클릭하는 고객이 있다 | 픽코파일럿(PicCopilot)이나 페이스 스왑 AI로 **모델 컷 10장** |
| 3 | **UGC 스타일 – 네이티브** | 너무 광고 같지 않은, 일반인이 폰으로 찍은 듯한 사진 | **투박할수록 클릭률이 높을 때가 많다** |
| 4 | **텍스트형 – 섬네일** | 정보성 | "양치 후 칫솔, 절대 그냥 두지 마세요" 같은 텍스트가 큼지막하게 박힌 섬네일을 캔바로 |

## 6. 무한 A/B 테스트 — 과학적인 **'승자 독식' 시스템**

준비된 카피들과 이미지를 조합해서 광고를 집행한다.
이때 사용하는 전략이 퍼포먼스 마케팅의 꽃, **'A/B 테스트'** 다.

### 테스트 세팅 방법

| 항목 | 설정 |
|------|------|
| **캠페인 생성** | 예산은 **하루 1~2만 원** |
| **광고 세트** | 타깃은 **'자동(Broad)'** 으로 둔다. **AI를 믿으라** |
| **광고 소재** | 준비한 카피와 이미지를 섞어서 **3~5개를 동시에 등록** |

**소재 조합 예시**

- 소재 1: **공포 카피 + 제품 배경을 삭제한 이미지**
- 소재 2: **혜택 카피 + 모델 이미지**
- 소재 3: **호기심 카피 + 텍스트 섬네일**

### 데이터 분석 및 대응

> 광고를 켜고 **3일(72시간) 동안은 건드리지 말고 기다린다.**
> AI가 학습하는 시간(**Learning Phase**)이다. **3일 뒤** 데이터를 열어본다.

| 판정 | 조건 | 대응 |
|------|------|------|
| **승자 (Winner)** | 클릭률 **2% 이상** **그리고** 구매가 일어남 | **예산을 증액(Scale-up)** 한다. 이것이 매출을 만드는 효자 역할을 한다 |
| **패자 (Loser)** | 클릭률 **1% 미만**, 돈만 나가고 구매가 없음 | **과감하게 종료(OFF)**. 새로운 AI 소재를 투입한다 |

> 이 과정을 반복하면, 결국 당신의 광고 계정에는 **'무조건 팔리는' 승자 소재들만 남게 된다.
> 이것이 시스템이다.**

## 7. 광고 효율의 마지막 열쇠 — **메시지 매칭 (Message Matching)**

**아무리 광고를 잘 만들어서 클릭을 유도해도 상세페이지가 엉망이면 효과는 없고 돈만 낭비된다.**
이를 방지하기 위해 '메시지 매칭'을 반드시 점검해야 한다.

**광고에서 했던 약속을 상세페이지 최상단에서 한 번 더 확인해줘야 한다.**

| 광고에서 본 것 | 상세페이지 최상단에 있어야 할 것 |
|---------------|------------------------------|
| "변기보다 더러운 칫솔……" | **"세균 99.9% 박멸! 변기보다 깨끗하게 관리하세요."** — 해결책이 바로 보여야 |
| "오늘만 1+1 행사" | **"1+1 이벤트 진행 중 (남은 시간 03:00)"** — 카운트다운 타이머가 보여야 |

> **광고 소재와 상세페이지 도입부는 '한 몸'처럼 움직여야** 이탈을 막고 구매로 이어진다.

## 8. 결론 — 마케팅은 '예측'이 아니라 **'대응'** 이다

> **10년 차 마케터도, 사장도, 심지어 AI도 모른다. 오직 시장의 '고객' 반응만이 정답을 안다.**

AI 시대의 광고 전략은 *"무엇이 터질까?"* 를 고민하며 **회의실에서 시간을 보내는 게 아니라**,
**'AI로 소재 100개를 만들어서 시장에 던져보고, 반응이 오는 것만 키운다'는 속도전**이다.

## 부록 A. 소재 조합 매트릭스

카피 소구 4종 × 이미지 앵글 4종 = **16가지 소재 축**.
소구당 카피 5개면 카피만 20개, 앵글당 이미지 10장이면 40장.

| | ① 제품(배경삭제) | ② 모델(페이스스왑) | ③ UGC 네이티브 | ④ 텍스트 섬네일 |
|---|---|---|---|---|
| **공포** | *(원문 소재 1)* | | | |
| **사회적 증거** | | | | |
| **파격 혜택** | | *(원문 소재 2)* | | |
| **호기심** | | | | *(원문 소재 3)* |

한 번에 3~5개만 집행하므로, **매트릭스는 후보 풀이고 집행은 표본**이다.
