## 현재 상태

- **지배 모델: OSMU 폭포수** — 채널은 병렬이 아니라 계층이다.
  코어 하나를 제대로 만들고 아래로 압축해 내려보낸다.
  ```
  레벨1 코어  (텍스트)  상세페이지 or 블로그 글   ← 사람 검수는 여기 한 곳
     ↓
  레벨2 마이크로 (이미지) 인스타 카드뉴스 3~5장      + 곁가지: 스레드/X 한 줄
     ↓
  레벨3 나노    (영상)   숏츠·릴스 15초 3단
  ```
- 공유 척추: `PersuasionSequence` (6단계 고정) — 레벨마다 접는 방식이 다르다
- ⏳ 대기
  - 04 문서: 숏폼 마스터 프롬프트의 `[구조]` 항목 (116p 이후)
  - 05 문서: OSMU 슈퍼 프롬프트의 나머지 3개 채널 지시문 (131p 이후)
- **⏳ 대기 중: 책 뒷부분 '마스터 플랜'** — 입수하면 `02` 문서의
  1절(채널 구성)과 6절(구축 순서)을 우선 재검토한다.
- 미확정: `02` 문서 9절 열린 질문 Q-1 ~ Q-15

## 읽는 순서

처음이면 `05`(전체 지도) → `01` → `03` → `04` → `02`. 설계만 볼 거면 `02` 하나로 충분하다.
