## 3. OSMU의 핵심 원리 — **콘텐츠 폭포수 모델**

콘텐츠를 변환하는 데에도 **순서**가 있다.

> **작은 콘텐츠를 크게 만드는 것은 어렵지만, 큰 콘텐츠를 작게 쪼개는 것은 쉽다.**

이를 **'콘텐츠 폭포수 모델'** 이라고 한다. 위에서 아래로 물이 흐르듯,
**정보량이 가장 많은 곳에서 작은 곳으로 흘러가야 한다.**

### 3단계 계층 구조

#### ① 레벨 1: 코어 콘텐츠 (Core Content) — **텍스트 100%**

| | |
|---|---|
| **형태** | 블로그 포스팅 / 상세페이지 |
| **역할** | 논리, 설득, SEO 검색 |
| **특징** | 가장 많은 정보를 담고 있고, **모든 콘텐츠의 '원천 소스'** 가 된다 |

#### ② 레벨 2: 마이크로 콘텐츠 (Micro Content) — **이미지 중심**

| | |
|---|---|
| **형태** | 인스타그램 카드뉴스, 피드 |
| **역할** | 비주얼, 브랜드 무드, 요약 |
| **특징** | 코어 콘텐츠에서 **핵심만 3~5장으로 요약**한 형태 |

#### ③ 레벨 3: 나노 콘텐츠 (Nano Content) — **영상 중심**

| | |
|---|---|
| **형태** | 유튜브 숏츠, 릴스, 틱톡 |
| **역할** | 도파민, 확산, 후킹 |
| **특징** | 정보보다는 **'임팩트' 위주**로, **15초 내외**로 짧게 쪼갠 형태 |

> **당신은 이제 레벨 1 하나만 제대로 만들면, AI를 통해 레벨 2와 3을 자동으로 생성할 수 있다.**

## 4. 채널별 문법 — 같은 재료도 그릇이 다르면 맛이 다르다

OSMU를 단순히 **'Ctrl+C, Ctrl+V'로 오해하면 안 된다.** 블로그의 긴 글을 그대로 캡처해서
인스타에 올리면 아무도 읽지 않는다.

> 미디어 이론가 마셜 매클루언은 **"미디어는 메시지다"** 라고 했다.
> 각 채널 고유의 **'문법(Grammar)'** 에 맞게 AI에게 변환을 지시해야 한다.

| # | 채널 | **판정 기준** | 문법 |
|:-:|------|-------------|------|
| 1 | **블로그/브런치** (Text) | **유용해야 본다** | 검색 키워드로 구성과 키워드 배치가 중요. **호흡이 길어도** 정보가 알차면 끝까지 읽는다 |
| 2 | **인스타그램** (Image) | **예뻐야 본다** | 절제한 비주얼 중심. 구구절절한 설명보다 **한 장의 감성적 이미지**나 **정보를 도식화한 그래픽**이 통한다 |
| 3 | **숏폼** (Video) | **재밌어야 본다** | 즉각적인 자극이 중요. **서론이 길면 안 된다.** 시각적 움직임(Motion)과 청각적 자극(Audio)으로 뇌를 깨워야 한다 |
| 4 | **스레드/엑스(트위터)** (Short Text) | **짧아야 본다** | 인사이트 중심. 긴 설명보다 **무릎을 탁 치게 만드는 한 줄의 통찰**이나 위트 있는 멘트가 확산(Retweet)된다 |

## 5. [실전 자동화 1] 블로그 → 인스타 카드뉴스

블로그에 "장마철 빨래 쉰내 없애는 법 5가지"라는 글을 썼다고 가정해보자.
이 긴 글을 **디자이너 없이** 인스타그램용 카드뉴스로 만드는 과정이다.

### 1) 스텝 1 — 챗GPT로 구조화하기

블로그 글을 그대로 복사해서 챗GPT에게 준다.

> **프롬프트**
> "이 블로그 글을 인스타그램 카드뉴스 **6장 분량**으로 요약해줘.
> 각 장마다 들어갈 **'헤드라인(임팩트 있게)', '본문(2줄 이내 요약)',
> '이미지 프롬프트(어떤 그림이 들어가야 할지)'** 를 **표(Table) 형식**으로 정리해줘."

### 2) 스텝 2 — 캔바의 '대량 제작(Bulk Create)' 치트키

**이 기능은 생산성을 10배 높여주는 치트키다.**

1. 캔바에서 '인스타그램 게시물' 템플릿 중 마음에 드는 것을 고른다
2. 좌측 메뉴의 **[앱] → [대량 제작]** 을 클릭한다
3. 챗GPT가 만들어준 **표 데이터를 복사해서 붙여 넣는다**
4. 템플릿의 텍스트 박스에 마우스 **우클릭 → [데이터 연결]** 을 누른다
5. **[계속]** 버튼을 누르면, 단 한 번의 클릭으로 **카드뉴스 6장이 순식간에 생성**된다.
   일일이 복사해 붙일 필요가 없다

### 3) 스텝 3 — AI 이미지 채워 넣기

캔바 내의 **'Magic Media'** 기능을 켜고, 각 페이지에 맞는 이미지를 생성해 드래그해서 넣으면 된다.

## 6. [실전 자동화 2] 카드뉴스 → 숏폼 영상

만들어진 카드뉴스 이미지를 **그대로 올리면 조회수가 잘 안 나온다.**
**동적인 요소**가 있어야 관심을 끌 수 있다.

### 브루(Vrew) 활용

국산 AI 툴인 **'브루(Vrew)'** 는 텍스트를 넣으면 영상으로 바꿔준다.

1. 챗GPT에게 **"이 카드뉴스 내용을 바탕으로 30초 분량의 숏츠 대본을 써줘"** 라고 요청한다
2. 브루의 **'텍스트로 비디오 만들기'** 메뉴에 대본을 붙여 넣는다
3. AI가 내용을 분석해서 **'어울리는 무료 영상 소스' + '배경음악' + 'AI 성우 목소리' + '자막'**
   을 한 번에 생성해준다
4. 여기서 **무료 영상 대신 나노 바나나로 만든 최상급 제품 이미지로 교체**해서 넣어주면 된다

> **결과물**: 전문 성우가 *"빨래 쉰내, 이것 하나면 끝!"* 이라고 외치면서 제품 이미지가
> 휙휙 지나가는 **완벽한 숏폼 광고가 10분 만에 완성**된다.

---

## 7. [실전 자동화 3] 사진 한 장에 생명 불어넣기

> "저는 영상 소스가 아예 없고 사진 한 장뿐인데요?"

걱정하지 않아도 된다. **최신 비디오 AI는 멈춰 있는 사진에 생명을 불어넣을 수 있기 때문이다.**

### 런웨이 (Runway)

제품 사진을 업로드하고 **'모션 브러시(Motion Brush)'** 기능을 켠다.
제품 주변의 커피에서 김이나 창밖의 나뭇잎처럼 **움직이는 부분만 붓으로 칠해주면** 된다.
그러면 분위기 있고 감성적인 **'시네마그래프(Cinemagraph)'** 영상이 된다.

### 클링 (Kling)

제품 사진을 업로드하고 **원하는 구도와 영상의 진행 순서**를 작성하면 제품 홍보 영상이
생성되고, **'StartFrame'과 'EndFrame'** 을 활용하여 영상의 **시작과 마지막 장면을 지정**하여
당신이 원하는 **영상 흐름을 더 디테일하게 설정**할 수 있다.

## 8. AI 시대의 끝판왕 — **'OSMU 슈퍼 프롬프트' 하나로 끝내기**

이 모든 과정을 매번 따로 지시하는 것은 번거롭다.
아예 **한 번에 모든 포맷을 주문하는 '슈퍼 프롬프트'** 를 만들어 저장해두고 쓰면 좋다.

### OSMU 슈퍼 프롬프트 예시

```
[역할] 나는 수석 콘텐츠 마케터야.
[소스] (여기에 블로그 글이나 상세페이지 내용을 붙여넣기)
[요청] 위 소스 내용을 바탕으로 각 채널의 문법에 맞는 4가지 콘텐츠를
       한 번에 작성해줘.

 · 인스타그램 피드용: 카드뉴스 5장 분량의 핵심 요약 텍스트
                   + 감성적인 캡션 + 해시태그 15개
```

> ⚠️ 원문이 여기서 다음 페이지로 넘어간다. **나머지 3개 채널 지시문은 131p 이후.**

                                    도파민·확산·후킹

만들어내야 하기 때문이다.
